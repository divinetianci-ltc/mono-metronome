# MONO 极简节拍器

一个纯静态、轻量、可安装、支持离线使用的极简节拍器。

- 30–300 BPM
- 1–9 拍，每小节第一拍重音
- 手机触控转轮、数字键盘和键盘快捷键
- 无广告、无追踪、无第三方依赖
- 支持添加到手机主屏幕并离线使用

## 使用

直接打开 GitHub Pages 网站。iPhone 请使用 Safari，点击“分享”→“添加到主屏幕”。Android 可使用页面“安装”按钮或浏览器菜单中的“添加到主屏幕”。

## 下载

点击仓库页面绿色 **Code** 按钮，再选择 **Download ZIP**。
